# Задания по JDBC

Решения находятся в `src/lesson04`, каждое задание запускается через `Task1`–`Task4`.
Сохраняются пакеты по урокам, обычные Java-классы и вывод на русском языке.
Комментарии в новый код не добавляются.

- `StudentDao` принимает `DataSource`, реализует `save`, `findById`, `findAll`,
  `update`, `delete` через `PreparedStatement`. Идентификатор выдаёт база.
- Студент содержит имя, название группы и балл от 0 до 100.
- Вставка 1000 студентов циклом и batch измеряется через `System.nanoTime()`.
  Данные, схема и режим транзакций одинаковы, базы для замеров отдельные.
- `enroll(studentId, courseId)` атомарно уменьшает `free_seats` и создаёт запись.
  Отсутствие мест возвращает `false` после `rollback()`, ошибки SQL также
  откатываются. Повторная запись запрещена; число мест не может быть отрицательным.
- H2-функция среднего балла группы регистрируется через `CREATE ALIAS` и вызывается
  `CallableStatement` с `{? = call ...}`. Для пустой группы возвращается `null`.

Для зависимостей и запуска используется Maven, исходники остаются в `src`.
Проверки выполняются на настоящей H2 в памяти.
